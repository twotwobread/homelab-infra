# Homelab Infra

AI Homelab의 실제 인프라 구성과 운영 절차를 관리하는 저장소입니다.

운영 설정과 재현 가능한 배포·점검·복구 절차를 담당합니다. 스케줄링 실험의 상세 분석과 Operator 구현은 별도 저장소에서 관리합니다.

## 작업 방식

현재 상태를 확인한 뒤 작은 변경 단위로 설계·구현·검증합니다. 운영 환경 변경 전 대상과 영향을 확인하며, 설계 계획과 실행 검증 결과를 구분합니다.

- [에이전트 작업 지침](AGENTS.md)
- [작업 흐름](.harness/workflow.md)
- [문서 관리 규칙](.harness/documentation.md)

설계·조사 등의 입력 자료는 필요할 때 `docs/`에 추가합니다. 운영 환경을 확인한 근거로 위키를 생성하며, 아직 존재하지 않는 문서나 완료되지 않은 검증을 가정하지 않습니다. 인증 정보와 kubeconfig는 커밋하지 않습니다.
